# data/raw — données réelles confidentielles

Ce dossier reçoit, **sur l'ordinateur de la doctorante uniquement**, les données agrégées fournies par Inwi.

- Son contenu est exclu de Git par le fichier `.gitignore` : seul ce README est versionné.
- Les données sont conservées dans un conteneur chiffré (VeraCrypt), conformément au plan de gestion des données (`docs/`).
- Elles ne doivent jamais être déposées sur GitHub, un cloud public ou un outil d'IA en ligne.
